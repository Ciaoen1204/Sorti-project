# 語言切換與配色

Android 與 PWA 的設定 → 語言可切換 `zh-TW` / `en`，偏好以 `sorti_language` 保存在各裝置，不透過重置導覽或重新建立帳號來切換。
`src/i18n/en.json` 為共用英文文案；`language.ts` 提供可訂閱狀態與顯示層翻譯。Native 使用 LocalizedUI 元件，PWA 對可見文字與標籤呼叫 tr；不修改業務 enum、資料庫、使用者姓名、物品名稱、輸入內容或既有歷史紀錄。
未列入字典的新文案保留原文，開發時需補翻譯。共用字典包含原始七題測驗／選項文案，但不改題數、選項、分數、人格式別或情境圖片。
AI 聊天與照片建議依語言生成；英文題透過常用領域詞對應檢索中文 RAG。新每日任務與照片回饋可依語言生成；既有已儲存的任務／紀錄不改寫。
深夜模式使用 `appearance.dark` 的中性炭灰／銀灰，不帶綠色主色，PWA 預設 CSS 與特殊狀態同步。淺色品牌配色不變。

## 維護

文案已由使用者明確同意送交現有 Google Gemini 服務進行翻譯；只提供介面文字，排除憑證、路徑、後端、測試與使用者紀錄。`scripts/translate-ui.py` 需要本機後端憑證，不在 App 執行；更新或擴大外傳範圍前，須確認授權仍適用。人工校訂常用導覽／首頁文案。
不要自動翻譯儲存的狀態值或名稱。既有歷史資料可保留原文，切換語言不會上傳或改寫它們。
