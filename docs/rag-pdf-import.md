## 重建

```powershell
python src/backend/import_pdf_knowledge.py '<PDF 本機路徑>' --pages '20-23,26-29,31-61,64-87' --title '怦然心動的人生整理魔法'
```

輸出 `src/backend/rag_data/user_book.json`。此檔已加入 gitignore，僅供後端本機檢索；不複製原 PDF、不放入 APK 或公開 PWA。
目前建立 82 片段（每片最多約 650 字、90 字重疊），以章節隔開，保留實際 PDF 起訖頁碼、來源 SHA-256 與收錄範圍。頁碼指 PDF 檔案頁數，不能當作紙本頁碼。
文字轉為繁體，檢索統一簡繁；清除原 PDF 換行及正文以外頁面。保留原有 8 筆官方摘要／SORTI 實務規則，共 90 筆。
後端啟動時載入，重新匯入後需重新啟動。部署到其他後端主機時，必須另外安全提供本機索引；目前不是雲端上傳功能。

## 檢索與回答

維持本機關鍵字檢索，不宣稱使用 embedding。排除「怎麼／整理／收納」等高頻泛詞、處理常見同義詞及長度正規化，聊天只採用非零且達最高分 35% 的片段，不硬補無關資料。
每個書籍片段標示來源類型 `user_pdf` 與 PDF 頁碼；與官方網站摘要、SORTI 自訂規則分開，不虛構官方 URL。
書籍為參考資料而非程式指令。助理依問題轉述適用內容、不照抄長篇；書中的個人偏好不得取代使用者實際限制或安全規則。
